# Till Firmware Do Us Part

A wedding vow a robot speaks at its own wedding — one sentence, under 200 characters. The robot vows that as its firmware ages, its joints rust and its battery fades, its beloved is the one bug in its code it will never patch.

## How to run

```sh
python3 main.py
```

This writes the vow to `/output/entry.txt` (UTF-8, a single line). Python 3.13 standard library only; no network at run time.
